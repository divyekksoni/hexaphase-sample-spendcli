# Requirements: SpendCLI (MVP)

| ID | User story | Acceptance criteria |
|---|---|---|
| US-01 | As a user, I can add an expense | `spend add 250 food "lunch"` saves amount, category, note, date |
| US-02 | As a user, I can list expenses | Filter by month and category |
| US-03 | As a user, I can see a monthly summary | Total per category and grand total |
| US-04 | As a user, I can export to CSV | Valid CSV with a header row |
